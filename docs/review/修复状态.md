## 已知副作用（非错误，但需后续 schema 配合）

- ~~**转化类技能**：消耗品 X 在结构化字段里消失~~ → **已修复**：补 `sourceResourceId`/`sourceResourceName`（6 条）。
- **`professions` 数组暂无消费方**：`src/` 只读角色自身的 `profession`，双职业要在排班生效还需改消费端。
- **`capacityBelow(16)` 边界**：中文「16格以下」含 16，下游若按严格 `<` 消费会漏档。
- **静态值不读 `per`/`cap`/`condition`**：`effectScore`/`skillSum` 对**所有房间**都只按 effect 的 `value` 求和，
  因此 `excludeAssist`/`countScope`/`orderTypeId`/`ignoreOrderEfficiency`/`product` 以及 `Defence`/`Attack` 补全
  都**不改变排班数值**；要等消费端实现 per/cap/条件计数后才生效。
