## 一、系统性问题

### 问题 1（主要）：加工站「具体材料子类」被统一泛化为大类，限定条件整体丢失 —— 影响 11 条

`detectProduct()`（`scripts/lib/effects.mjs:478-487`）优先采用 buff 的官方 `targets`（本批加工站多为 `F_EVOLVE` → `精英材料`），
**不再回退到描述中的具体材料关键词**。而原文描述才是权威，且明确限定了子类：

| 条目 | 原文限定 | 实为 product |
| --- | --- | --- |
| `workshop_formula_cost5[100]`（折桠·铁匠天赋） | 异铁组 | 精英材料 |
| `workshop_formula_device[000]`（贾维） | 装置 | 精英材料 |
| `workshop_formula_device[020]`（熔泉） | 异铁 | 精英材料 |
| `workshop_formula_device[021]`（折桠） | 异铁组 | 精英材料 |
| `workshop_formula_device[030]`（奥斯塔） | 聚酸酯 | 精英材料 |
| `workshop_formula_device[050]`（泥岩/谬因） | 源岩 | 精英材料 |
| `workshop_formula_device[060]`（维荻） | 酮凝集 | 精英材料 |
| `workshop_formula_device[070]`（特克诺） | 晶体 | 精英材料 |
| `workshop_formula_device[080]`（旅骨） | 手性屈光体 / 重相位对映体 | 精英材料 |
| `workshop_formula_device[111]`（号角） | 炽合金块 | 精英材料 |

后果：这些效果在排班里会被套用到**全部精英材料**配方上，覆盖面被显著放大（例如熔泉加工异铁以外的精英材料也会拿到 +90% 副产物概率）。
关键词本身在解析器词表里是存在的（装置/异铁/聚酸酯/炽合金块/酮凝集/晶体/源岩/手性屈光体/重相位对映体），只是被 `targets` 分支抢先返回。
建议：WORKSHOP 房间改为「先取描述关键词、取不到再用 targets」，或把子类写进 `condition`（`condition.type = materialSubtype`）。

### 问题 2：加工站心情消耗的 unit 整体健康，但存在 1 例漏判为 perHour

全库 29 条 `workshopMoodCost` 中 28 条 `unit=mood`（正确），
**仅 `workshop_formula_cost5[000]`（特克诺·熟极而流）被判成 `moodCostReduction` + `unit=perHour`**，属解析错误，已单列（第 18 条）。
即：提示中担心的「加工心情消耗误写 perHour」**不是系统性问题**，仅此 1 条。

### 问题 3：`unit=percent` 而非 `unit=probability`（命名约定，未判错）

提示要求 `workshopByproduct` 的 unit 为 `probability`，但全库 **91 条 `workshopByproduct` 一律为 `unit=percent`**，
且 `unit=probability` 在整个 operators.json 中出现 **0 次**（仅 `clueBias` 的规则表里出现过）。
由于 `percent` 与 value 的百分比语义一致且全局统一，本报告中**不判为错误**，仅提示：若规范以 `probability` 为准，需整体改名（涉及全库，非本批 77 条）。

### 问题 4：「恒定为 N」与「-N」共用同一编码，无法区分（3 条）

`workshop_formula_cost4[*]`（泥岩/止颂×2）描述为「相应配方的心情消耗**恒定为**2/4/3」，
编码为 `workshopMoodCost value=N unit=mood`，与 cost3 系列「-N心情消耗」的编码**完全同形**，无任何 `subtype`（如 `setTo`）区分。
排班若按「减免 N 点」理解即为错误语义。已全部判为存疑（第 15/16/17 条）。

### 问题 5：T3 品质前提未进入 condition（3 条）

`workshop_formula_drop[020/030/040]`（洛洛/蚀清/莱伊）原文带「产出 **T3** 品质的副产品时」前提，
编码中**无 condition 字段**，仅靠 `subtype=forceByproduct` 表达「必定产出」；同时 `forced` 值被剥掉了「组」后缀（聚酸酯组→聚酸酯、异铁组→异铁、固源岩组→固源岩）。
