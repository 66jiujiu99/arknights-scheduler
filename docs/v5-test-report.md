命令：

~~~bash
npm run test:optimizer
~~~

覆盖范围：

- 电力：3 制造 / 3 贸易 / 3 发电满级 = 810；5 制造 + 5 贸易超预算会报错。
- 龙门币：权重 100% 时选择赤金 + 龙门商法组合，与手算误差 < 0.01。
- 经验：选择作战记录组合，与手算误差 < 0.01。
- 合成玉：选择源石碎片 + 开采协力组合，与手算误差 < 0.01。
- 无人机：开关给同一方案带来的差异 = 5%。
- 心情：3 人房间 + 5 人中枢 = 0.65/h；12h 后发电站单人心情为 15。
- 手动模式效率不低于一键模式。
- 方案结构：槽位、拥有干员、队列内唯一、技能精英/等级未锁定。
- 组合：德克萨斯 + 拉普兰德同站触发，且收益上升。
- 练度建议只包含已拥有且技能未解锁的干员。
- 中枢同 buffId 不重复叠加。
- 源石碎片 / 开采协力在 Lv3 以下不会被使用。

## 4. 公式手算校验

- 3 人制造站 / 5 人中枢：1 - 0.1 - 0.25 = 0.65 心情/h。
- 12h 一班：3 人制造站剩 16.2；1 人发电站剩 15（发电站无 3 人减免）。
- 3-3-3 满级电力：3×60 + 3×60 + 4×65 + 60×3 + 10 = 810。
- 龙门币：贸易站 Lv3 的基础订单 2000/4.6h；赤金供给与订单需求按 min(1, supply/demand) 折算。
- 经验：Lv3 作战记录 1000/3h；Lv2 400/(80/60)h；Lv1 200/0.75h。
- 合成玉：2 源石碎片 → 20 玉 / 2h，Lv3 才可用。
- 分数归一化：LMD/30000、EXP/24000、玉/800、信赖/4000，再乘权重与心情系数。

## 5. 已知限制

- 仍然是启发式排班，不是全局最优求解器；组合/条件技能只按手动配置与简化规则计算。
- 订单质量、中间产物链、暖机、特殊订单没有完整模拟。
- 心情恢复按宿舍平均恢复估算，没有逐床模拟 20 个宿舍位。
- 无人机按 5% 固定收益估算，没有按发电站实际充能速度逐架计算。
- 森空岛 API 不返回加工站/回收站/活动室/副手，配置需手动补全。
