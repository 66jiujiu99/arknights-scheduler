# v5 测试报告（2026-10-19）

## 1. 自动化测试

命令：

~~~bash
npm run test:optimizer
~~~

结果：**22 / 22 通过**（20 个排班用例 + 2 个旧权重状态回归用例）。

覆盖范围：

- 电力：3 制造 / 3 贸易 / 3 发电满级 = 810；5 制造 + 5 贸易超预算会报错。
- 固定产物/策略：3 制造站分别产赤金/作战记录/源石碎片、2 贸易站分别龙门商法/开采协力，方案不会改掉你的选择；产出与手算误差 < 0.01。
- 经验：选择作战记录组合，与手算误差 < 0.01。
- 合成玉：选择源石碎片 + 开采协力组合，与手算误差 < 0.01。
- 无人机：开关给同一方案带来的差异 = 5%。
- 心情：3 人房间 + 5 人中枢 = 0.65/h；12h 后发电站单人心情为 15。
- 手动模式效率不低于一键模式。
- 方案结构：槽位、拥有干员、队列内唯一、技能精英/等级未锁定。
- 组合：德克萨斯 + 拉普兰德同站触发，且收益上升。
- 练度建议只包含已拥有、技能未解锁、且能提升龙门币 / 合成玉的干员；加工站 / 作战记录 / 会客室等不再提示。
- 中枢同 buffId 不重复叠加。
- 源石碎片 / 开采协力按“账号曾解锁”判断：账号有 Lv3 设施后，任意等级设施都能用；完全没解锁时才禁用。
- 固定产物/策略不会被算法改掉；每个设施都返回效率与心情消耗。
- 搓玉：固源岩配方按 2 个 + 1600 LMD/碎片，装置配方按 1 个 + 1000 LMD/碎片；按一图流 1-7 的 1.09 玉/理智折算理智消耗。
- 产销平衡：赤金/源石碎片的制造供应与贸易需求分别计算，产出与有效效率按较低一侧；净龙门币扣除搓玉 LMD 消耗。
- 每个设施（制造/贸易/发电/中枢/会客/办公/训练/加工/回收）都能读取 `efficiency` / `moodPerOp` / `moodTotal`。
- 旧权重状态回归：改动一个值时其余权重保持有效，不会出现 NaN / 10000%。

## 4. 公式手算校验

- 3 人制造站 / 5 人中枢：1 - 0.1 - 0.25 = 0.65 心情/h。
- 12h 一班：3 人制造站剩 16.2；1 人发电站剩 15（发电站无 3 人减免）。
- 3-3-3 满级电力：3×60 + 3×60 + 4×65 + 60×3 + 10 = 810。
- 龙门币：贸易站 Lv3 的基础订单 2000/4.6h；赤金供给与订单需求按 min(1, supply/demand) 折算。
- 经验：Lv3 作战记录 1000/3h；Lv2 400/(80/60)h；Lv1 200/0.75h。
- 合成玉：2 源石碎片 → 20 玉 / 2h，Lv3 才可用。
- 分数归一化：LMD/30000、EXP/24000、玉/800、信赖/4000，再乘内部默认比例与心情系数。

## 5. 已知限制

- 仍然是启发式排班，不是全局最优求解器；组合/条件技能只按手动配置与简化规则计算。
- 订单质量、中间产物链、暖机、特殊订单没有完整模拟。
- 心情恢复按宿舍平均恢复估算，没有逐床模拟 20 个宿舍位。
- 无人机按 5% 固定收益估算，没有按发电站实际充能速度逐架计算。
- 森空岛 API 不返回加工站/回收站/活动室/副手，配置需手动补全。

## 7. 搓玉与产销平衡

- 固源岩配方（游戏数据/一图流）：`固源岩 ×2 + 龙门币 ×1600 → 源石碎片 ×1`。
- 装置配方：`装置 ×1 + 龙门币 ×1000 → 源石碎片 ×1`。
- 1-7 折算：一图流 2026-10-20 数据为 `1.09 合成玉/理智`；1 碎片约 9.17 理智。
- 方案页新增“产销平衡”和“搓玉消耗”：显示制造供应、贸易需求、两侧有效效率、固源岩/装置/龙门币/理智消耗、净龙门币。
- 例：真实账号当前配置下赤金贸易有效约 65%、开采协力约 72%，两者都因制造侧供应不足而开不满；产出已按制造侧计算。
